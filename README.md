# Мои дела — трекер дел (PWA)

Простое приложение-список дел для телефона. Открывается сразу на списке: отметил дело — оно уходит с экрана (и его можно вернуть). Редактирование списка — в настройках. Работает офлайн, устанавливается на рабочий стол Android как обычное приложение.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Всё приложение: вёрстка, стили, логика |
| `manifest.webmanifest` | Описание приложения для установки на телефон |
| `sw.js` | Офлайн-кэш (сервис-воркер) |
| `icons/` | Иконки приложения |
| `mockup.html` | Дизайн-макет (не нужен для работы) |
| `serve.js` | Локальный сервер для просмотра на компьютере |
| `gen-icons.ps1` | Скрипт, которым сгенерированы иконки |

Данные хранятся в самом браузере (localStorage), никуда не отправляются.

**Стартовый список дел** зашит в `index.html` (массив `DEFAULT_TASKS` в начале скрипта): при первом запуске, пока пользователь ничего не менял, на главном экране отображается именно он. Поменять список — отредактируйте этот массив.

## Посмотреть на компьютере

```bash
node serve.js        # поднимет http://127.0.0.1:8123/
```

Открыть http://127.0.0.1:8123/ в браузере. В DevTools (F12) можно включить режим телефона и тёмную тему.

## Выложить в интернет и поставить на телефон

Приложению нужен обычный HTTPS-хостинг статики. Проще всего — GitHub Pages:

1. Создайте аккаунт на github.com (если нет).
2. Создайте репозиторий, например `dela`.
3. Загрузите в него файлы: `index.html`, `manifest.webmanifest`, `sw.js`, папку `icons` (остальные файлы не обязательны).
4. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main → Save**.
5. Через минуту приложение будет по адресу `https://ИМЯ.github.io/dela/`.

На телефоне (Redmi, HyperOS):

1. Откройте ссылку в **Chrome**.
2. Меню (⋮) → **«Установить приложение»** (или «Добавить на главный экран»).
3. Иконка появится на рабочем столе — приложение открывается на весь экран и работает без интернета.

## Обновление приложения

Замените файлы на хостинге и **увеличьте номер версии** в первой строке `sw.js` (например, `dela-v1` → `dela-v2`) — тогда телефоны подтянут новую версию при следующем открытии.
